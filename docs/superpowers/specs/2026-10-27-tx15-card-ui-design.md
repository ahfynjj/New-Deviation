# New Deviation TX15：卡片与分组表单样式稿

2026-10-27，用户提出接近 ETHOS 的触摸友好样式，并同意先出主菜单和 Mix
两页效果稿。默认配色由开发方选择：深灰底、橙色强调。本稿是视觉提案，
不是已刷入的界面，也不是电脑模拟器；UI02 菜单触摸固件保持不变。
2026-10-28：用户认可主菜单，指出 Mix 稿信息过少。修订为紧凑列表与曲线
同屏；滚轮修复另见 2026-10-28-tx15-wheel-and-mix-density.md。

## 方向

采用「入口用卡片、参数用表单」。另一种所有层级均用大卡片的方式，会使
复杂混控大量翻页，因此不采用。保持 Deviation 的菜单层级、进入顺序、
复杂混控语义和 OK/Cancel 保存机制；独立绘制图标，不使用 ETHOS 代码或素材。

## 两页稿

- 主菜单：三列两行，每块 146×96，40 像素高的返回/翻页按钮；保留原菜单
  枚举顺序。Transmitter menu 的卡片简称 Transmitter，进入页标题仍使用
  完整名称。Storage test 位于第二页，不删功能。焦点橙色描边，点击松手
  进入，滑动翻页；滚轮逐卡移动，ENTER/EXIT 行为保留。
- Mix：复杂混控第一条为例。左侧五行 Source、Switch、Mux、Scale、Offset，
  每行 292×40，行间 4 像素；标签 16 像素、值 20 像素。右侧同时展示曲线
  预览和输出值，底部独立 152×40 的 Curve 入口。Source 示例处于编辑状态，橙框
  配合 EDIT 字样；普通焦点与编辑态需在最终控件中区分。参数入口点整张
  参数行，不要求点中细箭头。曲线与输出只读，点 Curve 进入编辑；底部
  Cancel / More / OK 各 144×40。
- More 是同一混控条目的补充字段分页，不是混控算法。
  最终字段分组需覆盖 Switch、Mux、Src、Curve、Scale、Offset、Trim、
  模板及混控条目选择，保持旧回调和保存流程；不能省略复杂混控功能。
  示例右上 Mix 1/2 为条目序号，底部 More 1/2 为字段页序号。

## 色彩与资源

背景 #14181E，卡片 #232A33，边框 #35404D，正文 #F3F5F7，次级文字
#AEB8C4，强调 #FF9E32。最终按 RGB565 量化；不依赖渐变、模糊、阴影动画。
图标用线段/几何图形绘制；固件资源当前 464375/524288 字节，不能把整张
PNG 当界面塞入固件。效果稿使用 Segoe UI 表达字号和层次；最终应优先复用
现有 23bold/较小字体并核对截断，不因预览采用系统字体而默认引入大字库。

所有操作区至少 40×40，卡片间留空隙。首批保持英文，中文字体不是本轮
新增范围。电压、输出百分比及模型字段均为示例数据，不表示当前实机读数。
