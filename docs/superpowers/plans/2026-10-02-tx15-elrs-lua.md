# TX15 ELRS / Lua 实施计划

> 执行方式：使用 executing-plans，单代理顺序实施；沿用已批准的快速推进方式。

**Goal:** 内外置ELRS均可由官方Lua脚本配置，并保持原生Deviation通道发送。
**Architecture:** 有界CRSF路由与硬件适配器分离；Lua通过兼容API访问选定模块。
**Tech Stack:** C、STM32H750、CRSF、Lua；现有原生GUI/输入。
**Spec:** [设计](../specs/2026-10-02-tx15-elrs-lua-design.md)

## 全局约束与重点

RF默认关闭；不写Flash；不开发模拟器；两个槽位分别验收；脚本失败不得阻塞控制。
重点检查：队列满、坏帧/超长、旧会话回复、模块关闭/切换、通道数/数值越界。
每批一次相关检查和构建，新增问题才复测；后续高风险硬件恢复流程集中审查。

## 1. 帧与路由核心（本批）

文件：`src/protocol/transport/crsf_link.[ch]`、`utils/hardware/tests/test_crsf_link.py`、`utils/hardware/tests/crsf_link_test.c`。
接口：初始化/选择slot返回generation；通道更新；脚本push/pop；经校验的整帧receive；service调用硬件send回调。
send必须同步复制整帧并以返回值表示接受/忙，不能保留指向队列的指针；service每次最多一帧。

- [x] 先写失败测试：独立CRC向量、通道位打包、限幅、队列背压、RC优先、切换清空和过期回复。
- [x] 实现无heap核心；TX4帧/RX8帧有界FIFO，仅一个选定slot，最新RC覆盖未发送旧RC。
- [x] 主机执行实际C代码，完成ARM交叉编译；不接入运行中的RF。
- [x] 记录边界，纳入本批提交。

## 2. TX15双硬件适配与模型选择

文件：`hardware/tx15/board/rf_uart.[ch]`（新）、`src/target/tx/radiomaster/tx15/rf.[ch]`（新）、模型配置/页面相关文件。
核对内外置电源、UART、双工/反相和DMA/cache责任，完成停止/清空/原固件恢复契约。
模型保存两个槽位设置与单一启用选择；持久化未接入时明确RAM有效。
用帧分段/噪声/超时测试验证字节解析；实机先识别内置模块，再外置，继而接收端通道验证。
通道映射与CH5解锁语义单独核对，禁止沿用混控验收模型直接发射。

## 3. 官方ELRS脚本运行

固定脚本提交/哈希与Lua版本；新建 `src/lua/` 运行器和兼容API，不引入EdgeTX应用框架。
实现init/run/退出、lcd、事件、getTime/getVersion、bit32和真实model.getModule；CRSF API连接核心。
先错误/超预算/内存耗尽测试，再上板读参数和写回；读取列表不算参数保存成功。

## 4. 使用体验与实时验收

脚本工具入口、TF文件加载、内外置选择。Lua帧限时、GC和调度时序必须实测。
验证两槽位参数设置、脚本中止后通道连续、换模型/模块无错路由、断链安全。
首期不承诺双模块同时发射、Widget/混控Lua、全EdgeTX API或预编译字节码兼容。

## 进度

核心ARM对象text=810字节、无全局data/bss，每个link结构912字节（主机测试sizeof）。由于尚未被RF适配器调用，最终应用中会被链接器GC去除；不宣称实机已收发。
测试覆盖64字节边界/逐字节损坏、16路跨字节打包、极值、忙/满队列、FIFO环回、RC优先与最新值、槽位切换/同槽重开/关闭、过期generation和回绕、错误扩展目的地址。
Ruling: 核心放入 `src/protocol/transport/`，避开旧构建的 `protocol/*.c` 自动模块收集，防止影响其他机型。
下一动作：第2批先核对内置UART/恢复，然后设备发现。用户无外置模块，外置物理验收待模块到位；核心两槽位均已有软件检查。

2026-10-03：第4批接入固定官方r18脚本和Lua5.2.4，新增原生运行器、彩屏/事件/API、

VM预算、嵌套pcall/xpcall退出、OOM、路由变更、finalizer绕过及UART忙均有检查。
审查发现ELRS C0/C1箭头不兼容原生UTF-8解码；已补字符映射、UTF-8验证和前瞻填零，并加入回归。
C库/GC不是可抢占任务，实时通道保障仍需后续实机时序验收。当前准备实机，不将构建算成上板通过。

首次实际Lua运行111次，识别33字段并开始参数加载，随后触发旧预算退出；原固件恢复，无Fault。

55项检查和116对象ARM通过，完整Lua菜单仍待复测。记录见2026-10-03实机日志。
