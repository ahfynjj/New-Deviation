# TX15 native simulator input increment

Spec: `../specs/2026-09-21-tx15-native-design.md`.
Base: `5650fd0c84874348dc7362a87fc816fae043b5eb`; branch `dev/tx15-inputs`.

Continue the approved native Deviation design. No other firmware framework,
physical pin guesses, device writes, or ELRS hardware claims in this increment.

## Task 1: Factory input profile

Replace the DEVO8 placeholder with four stick axes, S1/S2, SA-SD three-position
switches, SE latching button, SF momentary button, and six mutually exclusive
selector positions. Retain four trim pairs and Deviation navigation semantics.
Source names: AIL/ELE/THR/RUD, S1/S2, SW A0 through SW F1, and 6POS0..5.
Standard mixer defaults: flight mode SA, gyro SB, aileron rate SC, elevator
rate SD, throttle hold SE. Internal C aliases are not model import aliases.

Tests first: exercise production input reads, key repeat, release/focus loss,
switch one-hot invariants, selector bounds, and dial extremes in a compiled C
harness. Then connect target hooks to the real FLTK event path.

## Task 2: Explicit model compatibility

Reject unknown source/button names for this host target. Preserve the previous
model on failed reads/templates; prohibit saving after a failed model read until
a successful load/reset. Show a visible load error. Do not silently convert old
switches to None or overwrite their files. Canonical TX15 sources must round-trip
through actual CONFIG_WriteModel/CONFIG_ReadModel. Supply reviewed TX15 copies of
the three bundled templates using old switches, without modifying user models.

Tests first: compiled integration harness linked against actual emulator objects
exercises load/save, invalid source/button rejection, template rollback, and file
preservation. Capture main/mixer/curve after adapting the fixtures.

## Task 3: Verification and handoff

Run tool regressions, the 79 existing mixer tests, both emulator builds/captures,
and changed-code lint. Update input/compatibility docs and TODO, obtain one fresh
whole-increment review, fix important findings, commit and push the development
branch as already authorized.

## Review focus

Check event fallthrough and key release, shift/auto-repeat, calibration count,
one-hot switch ordering, standard mixer defaults, file preservation after load
failure, parser side effects, and that existing DEVO targets retain behavior.
Hardware wiring, RF and full GUI interaction remain outside this host increment.
