> **For agentic workers:** Use superpowers:executing-plans for inline execution. 按用户要求控制 token 消耗，不默认启用多代理；每阶段围绕一个实机可见成果，阶段完成才提交一次代码与简短记录。

**Goal:** 尽快在 TX15 MAX 上显示并操作原生 Deviation，随后打通摇杆→混控→ELRS 接收端的链路。

**Architecture:** 保留 Deviation 页面、模型和混控核心，仅新增 TX15 平台适配。沿用已验证的电源、PLL128、SDRAM 和 RAM 装载路径。硬件参考可查 EdgeTX 板级代码，但不采用其应用框架。

**Tech Stack:** 原工程 C、STM32H750、LTDC/面板控制接口、SDRAM、现有 Arm GCC、PWLINK2/CMSIS-DAP、CRSF。

**Spec:** `docs/superpowers/specs/2026-09-21-tx15-native-design.md`。本计划依据用户 2026-09-28 对速度/token 成本的要求，覆盖旧计划的执行顺序；继续遵守原生 Deviation、实机优先。后续明确允许的板级参考优先于旧设计中的历史禁止条目。
