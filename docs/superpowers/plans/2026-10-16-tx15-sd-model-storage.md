# TX15 SD 卡语音与模型存储增补计划

日期：2026-10-16。用户要求语音包和模型文件存到SD卡。本计划更新语音计划中“模型继续以NOR为主要存储”的早期范围；当前固件尚未实现SD文件后端，本轮只核对现状并记录要求，不改固件或介质。

用户已明确介质为“遥控器内置存储”，不以另装可取出TF卡为前提。本文SD:/是该内置卷的逻辑根目录。固定目标资料及共享驱动指向SDMMC1的SD协议路径；真实芯片类型、容量、分区和文件系统尚未实测，不仅凭“内置”称呼认定为eMMC。

## 当前实际行为

- 可持久保存的模型1、操纵模式与六路校准打包在v2快照，保存于外部NOR的0xF0000..0x100000设置区，具有双记录保护。依据 `settings_nor.h`、`settings_nor.c` 和 `config/model.c` 的TX15_PERSISTENCE分支。
- 编译内置资源中存在默认模型INI；它是启动模板，不是用户修改后的SD模型文件。当前 `romfs.c` 文件层只读内置资源，不能写SD。
- 尚无可从SD读取的语音包。AUD0仅合成提示音，A1的WAV/PCM/请求队列为离线核心，尚无实际文件播放调用。

## 用户要求与选定边界

语音资源与用户模型以SD卡为主要存储。目录使用项目独立模型路径，保留标准语音包布局：

```text
SD:/
  SOUNDS/
    cn/SYSTEM/*.wav
    cn/*.wav
    en/SYSTEM/*.wav
  NEWDEVIATION/
    MODELS/model1.ini
    MODELS/model2.ini
    AUDIO/                  # 独立语音配置的双记录
```

这些是目标路径，尚未生效；最终文件名/版本/CRC伴随信息在实现文件事务时固定。模型采用可读INI并增加New Deviation版本信息，沿用Deviation配置语义；不能把EdgeTX模型文件直接当成本项目模型读取。

固件/启动器继续在Flash。设备专属摇杆校准及必要的设备设置留在机内，不能因换卡或换模型被另一台遥控器的校准覆盖。语音配置按现有计划单独保存在SD的NEWDEVIATION/AUDIO。

首次迁移从现有NOR恢复模型并导出到项目目录，读回/解析比对成功后再启用SD模型；保留当前NOR快照作为迁移备份。SD成为主要模型来源后，必须去掉现有“读取INI后再用NOR模型覆盖”的顺序，校准恢复与模型恢复分开处理。现有卡上其他目录不格式化、不覆盖。

缺卡或模型损坏时保留菜单与明确错误状态，加载有效模型前不启用射频；不得静默换成另一个模型或用错误模型重新保存覆盖文件。备份恢复应由用户明确选择。卡上文件是权威来源，运行时仍使用已经校验并完整装入RAM的模型，禁止混控/射频中断访问文件。

## 分步实施

### S0：介质与时钟确认

- [x] 用户确认使用内置介质；固定TX15目标声明SD_SDIO=SDMMC1，共享驱动明确SDMMC1为internal后备，另一读卡接口检测使用SDMMC2/PH8。GPIO候选为PC8..11/PC12/PD2、AF12，实际身份/容量和读操作仍待验证，不能把源码核对当作实机连接成功。
- [ ] 只读读取内置介质身份、容量和分区；以实际命令应答区分协议，不格式化、不尝试未验证的写入或自动切换到外置介质。
- [ ] 给SDMMC内核时钟与DMA分配所有者；音频A0当前独占PLL2，不能直接复用一个会在退出Audio test时被关闭的时钟。保留CPU/LCD/ELRS基准。
- [ ] 先提供介质身份、文件系统及目录只读诊断，覆盖无卡、超时、坏分区并确认输入/RF继续服务。

### S1：有界文件读取，先支持语音资源

- [ ] 新增 `hardware/tx15/board/audio_storage.{h,c}` 和 `src/audio/files.{h,c}`，评估已有FatFs；每次最多一个512字节sector的异步请求，有截止时间，不在中断/混控中读文件。
- [ ] 在SOUNDS内规范化128字节以内路径；拒绝越界及路径穿越，保留当前字体/ELRS Lua的ROMFS，不全局替换stdio。
- [ ] 先用生成的文件做失败测试，ARM构建后再读取实际卡上WAV样本；A0发声验收通过后接播放器。此项复用语音计划A2。

### S2：模型文件读写与多模型

- [ ] 新增 `src/target/tx/radiomaster/tx15/model_storage.{h,c}`，拆分 `config/model.c` 原生持久化分支的校准/模型来源及保存结果。
- [ ] 对临时Model解析、检查来源/混控边界/内外置RF设置/微调/曲线等，全部通过后才替换运行模型；失败保留原RAM状态并报告原因。
- [ ] 用临时文件、同步/关闭、读回校验、保留上一个有效副本与启动恢复实现保存事务；测试每个写入中断点，不能假设FAT改名天然具备完整掉电原子性。
- [ ] 实现模型列表/选择/新增/复制/删除和当前模型编号保存，验证两个不同模型切换及正常关机重启；文件读写失败不得显示“保存成功”。

### S3：现场迁移与验收

- [ ] 已有模型1导出到项目目录并读回比对；确认混控、微调、内外置RF选择不变，校准仍来自本机。
- [ ] 验证关机重启、多模型、缺卡/损坏文件/保存中断恢复及语音并行读取；保留NOR迁移备份与现有USB回退包。
- [ ] 为内置介质提供电脑端USB文件导入/导出，支持复制SOUNDS和备份/恢复项目模型；在文件系统读写成熟后再选定专用文件传输或受控USB大容量存储实现。文件传输期间停止射频并协调文件系统所有权，不能电脑/遥控器同时写同一卷。现有固件更新器尚无此功能，不要求用户拆板接读卡器。

各阶段先失败测试、最小实现、相关回归及ARM构建，再安排一次合并实机验收。语音计划原20–33人日是原语音范围估算，不能直接视为已包含本次多模型文件读写与迁移的承诺。当前优先完成SD介质/文件访问基础，以便语音与模型共用，现有AUD0仍待用户试听。
