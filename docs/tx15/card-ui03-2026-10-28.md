# UI03：卡片菜单与 Complex 混控试用版

用户确认图标卡片主菜单及紧凑 Mix 稿后实施。原生 Deviation 运行时、
菜单枚举顺序、模型与保存 ABI、ELRS Lua 均保留。含 UI02-R1 一格一步滚轮。

## 本版可试用内容

- MAIN MENU、Model menu、Transmitter menu：三列两行卡片，几何图标、圆角、
  深灰底与橙色焦点。复用当前原生字库，较长名称自动缩用小字体；不是将
  桌面效果稿 PNG 烧入固件。工具卡片本轮使用统一工具图标。
- Complex 混控：Source/Switch/Mux/Scale/Offset 五行与实时曲线、输出条同屏。
  曲线类型字段与 Edit curve 入口分开，底部 Cancel / More / OK。
- More：混控数量、当前条目、Trim。顶部保留模板选择与当前条目/总数。
  Source/Switch 仍支持拨动控件捕获；S1/S2 来源捕获逻辑保留。
- 点参数进入/结束编辑，用滚轮修改；短 EXIT 结束编辑，点 OK 保存，
  Cancel 丢弃本次混控改动。普通数值本轮尚无触摸数字键盘或加减弹窗。
  进入新页面后先释放屏幕，避免同一次接触贯穿两页。

新布局首先覆盖 Complex。Simple/Expo 与曲线/重排等子页面仍保持原布局和
滚轮操作，触摸不会分发给它们的小控件。Lua 继续使用脚本原界面和滚轮。
图稿的输出数值、桌面字体和部分图标细节不作为当前固件逐像素承诺。

## 构建与验证

`TX15_CARD_UI=1` 依赖 `TX15_MENU_TOUCH=1`；`HAS_TOUCH=0` 仍保持。
仅在三类菜单与 Mix 页应用主题，离开时恢复 Display，避免覆盖子页面主题。
板级共享 I2C、Map 0、CANCEL、页面切换取消、关机/Lua 暂停策略沿用 UI02。
不更改 BL、GPIO、电源、射频、音频或存储驱动。

## 一次 USB 验收

包：`local/tx15-usb-release/tx15-card-ui03-20261028.ndu`。
EXIT+开机进入 USB UPDATE，用现有工具更新，完成后重启，About 应为 UI03。
保留启动器、模型和校准；回退包为 `tx15-wheel-1step-ui02r1-20261028.ndu`。

1. 接收机断电，检查三类菜单卡片：点选、滚轮、翻页、EXIT 和返回焦点。
2. 选一个测试模型/混控，切到 Complex，检查五行、曲线、输出条、More。
3. 点 Scale，转滚轮改值，再短 EXIT；先 Cancel 返回，重进确认未保存。
4. 再改一个参数，OK 保存，重进确认值保留；确认模型其余参数未变化。
5. 测 Source/Switch 捕获、切混控条目、曲线/重排返回、正常关机重启和校准。
   再按既有流程验收 ELRS；本版不以 host 测试代替连续连接的实机证据。

若有布局/操作异常，记录模板、字段和操作顺序；可从同一 USB 入口回退。
