# TX15 UI01：触摸基础与独立诊断

按已批准的 480×320/触摸设计完成 P1 软件候选。新增 MAIN MENU → Touch test，
页面标题 TOU1、About 版本 UI01。当前不派发菜单或 Lua 触摸事件，HAS_TOUCH
保持 0；实体滚轮、按键、自动来源捕获和既有混控流程继续使用原路径。

## 已实现

- 共享 I2C4 事务接口：1/2 字节寄存器前缀、最多 4 字节数据，沿用 controls.c
  的互斥、约 98kHz 总线和输入故障恢复责任，统一音频/触摸传输。
- 对公共事务使用同一起点的 128000 周期（CPU128MHz，1ms）期限，接受就绪
  标志和最终成功前均检查；保留停止/清标志之前的终端状态。轮询次数也有
  上限，DWT 不动时不会无限等待。真实总线时序和 RF 间隔仍待实机测量。
- 手动进入诊断页才开始探测 0x5D/0x14，严格验证 GT911 Product ID，再只读
  0x8048 分辨率配置。报告以分步短事务读状态和单触点，成功后只向已识别
  设备的 0x814E 写 0 确认数据；不改控制器配置或 GPIO。
- 原始坐标到 480×320 的交换轴、翻转、缩放与边界检查；DOWN/MOVE/UP/CANCEL
  队列，多指、触点 ID 变化、非法坐标、通信故障及队列溢出不会变成点击。
  “暂无新报告”不会误判抬起。Map 为本页试验值，不写设置记录。
- 诊断页显示 ID、地址、传感器尺寸、原始/映射坐标、触点数、事件和总线
  结果，附小型屏幕预览；仅重画变化信息，退出即停止采样。
- 新增 TX15 布局常量：36px 标题区、244px 内容区、40px 操作区、40px 行高。
  此版用于诊断页，尚未整体迁移 MAIN MENU/Mix 布局。

硬件采样经真实 app/runtime 服务运行，期间不调用 GUI 或重入 Lua。
控制器复位/中断引脚沿用旧记录仍需核对，本版不配置它们。因此若控制器
尚在复位或休眠，可能显示 No GT911；不能凭此判断触摸屏损坏。

## 软件验证

46 项主机回归通过，包括共享总线、实际诊断页及运行循环、触摸解码与事件、
原开关与音频时限、显示换帧、关机取消、官方 Lua、RF/模型/校准与自动捕获。
各模块先有失败回归再实现；独立审查指出的一处整笔事务期限缺口已复现、
修正并再次审查通过。155 个 ARM 对象构建并验证载入段、ELF 入口及 USB 包。
新文件编译未报告警告；既有第三方/旧代码警告仍存在。

审查者另外尝试的 6 项未激活便携 PCM/queue/WAV 检查，因其原有 harness
缺少 string.h 搜索路径未完成，不包含在上述 46 项通过计数内。这些便携
音频模块本轮未修改。详细模块列表和证据见
`evidence/2026-10-25/touch-p1-candidate.json`。

资源仍为 464375/524288 字节，未加入新位图。模型/校准 ABI 和启动器均不变。
UI01 包含 RD02 的显示换帧逻辑；RD02 的视觉、速度和 RF 实机验收仍待反馈。

## USB 更新与一次实机验收

文件：`local/tx15-usb-release/tx15-touch-p1-ui01-20261025.ndu`

大小 713960 字节；SHA256：
`aa5cb37e7c37580cad2a14a94818158a07d002088a78476ad405399f661e1a14`。
Boot API 1、settings ABI 1、包头/载荷 CRC 与 ND15 段验证通过。

1. EXIT+电源进入 USB UPDATE，使用现有 NewDeviationUpdater 选择本文件更新。
   重启后 About 应为 UI01。此开发测试先保持接收机断电。
2. 用滚轮进入 MAIN MENU → Touch test，观察是否 Ready、ID 是否为 911、
   地址及传感器尺寸。手指依次点屏幕四角、中心并滑动，观察 Raw/XY 及预览。
   预览是缩小后的屏幕坐标图，不是手指必须点中的控件。
3. 如方向不一致，用滚轮选 Map + 循环试验 0..7，记下同向跟随时的编号。
   这些值不会保存，下一轮按实际结果固定板级映射。
4. 若 No GT911/Error，请只记录页面 ID、Bus、ST，不要自行改接线。
   无需重新焊调试线；后续根据读数核对触摸复位/地址条件。
5. EXIT 后确认原菜单、四轴/S1/S2、开关/微调和音频仍正常；正常退出诊断后
   再按已有方式检查接收机连续连接。视觉与操作流畅度也一并反馈。

本轮没有访问设备或改写 Flash。触摸芯片身份、复位条件、方向和实际操作
仍待上述实机确认；完成后再进入 MAIN MENU/Mix 的布局和触摸交互适配。
上一版 RD02 包仍保留，可通过同一 USB 入口回退。
