## Stall located: arena search

Profile bench `local/reset-halt-power-20261003-122823.json`: the repeatable
111-call stall consumed 292ms. Of that, allocation callbacks consumed 264ms
across 998 calls; explicit GC was 11ms across three calls (overlaps allocation),
with zero drawing calls and 3000 counted VM instructions. Startup was 819ms,
peak 93320B. The failure precedes drawing; repeated linear scans over live
arena blocks are the identified performance bottleneck. No MCU fault;
ticks 569→5297, loops 3→636, RF stopped and original firmware resumed with
no cleanup errors.

Replace full physical-block scans with size-class free lists and immediate
neighbor coalescing. Fixed-width offsets preserve 8-byte alignment and keep
metadata size identical in host/board tests. The arena remains bounded at
160KiB; run/init limits and official script stay unchanged. A deterministic
2000-small-object search-work regression failed on the previous allocator and
passed on the replacement; add 20000 fragmented realloc/free operations,
preserved-byte/no-overlap checks, and whole-arena recovery after freeing.
Physical speed and complete menu acceptance still require the optimized build
to be loaded.

## Selection save/readback build

New bounded `crsf_tools` policy uses matching, complete metadata for visible
TEXT_SELECTION fields. Values must be in range and reference a nonempty
option; arbitrary writes, command/info/folder/string/float/integer fields remain
blocked. Format reference: [TBS TEXT_SELECTION definition](https://github.com/tbs-fpv/tbs-crsf-spec/blob/main/crsf.md#text_selection).
The exact official-script statistics request EE EA 00 00 is separately allowed.
API and UART enforce the same policy; permanently forbidden queued frames are
removed, while busy/settling keeps legitimate frames.

`TX15_ELRS_WRITE=1` requires `TX15_ELRS_LUA=1`; default Lua parameter behavior
stays read-only. A UART-accepted write records the original/index/desired value;
complete reread after 200ms with matching schema/index records VERIFIED.
Mismatch, 3s timeout and cancellation are separate outcomes. No automatic
save retries or rollback; the user explicitly saves and restores the setting.

Focused review found an important clock-origin mismatch: Lua rereads 200ms
after the save event, whereas UART acceptance may be delayed. Native UART mock
and original Lua + real policy + 40ms delay both failed before the fix. The
same-field reread now waits in the queue until 200ms after UART acceptance.
57 checks pass, including original-script save/reload/restore, real 33-field
replay, malformed/hidden/blank choices, schema mismatch, >512B assembly,
timeout wrap, cancellation and busy/forbidden queue behavior. CRSF has no
request nonce; verification assumes bounded local-module reply latency and
does not claim exclusion of arbitrary delayed duplicates or cold-start
persistence. No further important review issues reported.

## Continuous RC candidate (software only)

Native CRSF model options (Off/Internal/Ext pending), a separate AETR bench
model, and periodic RC submission are implemented. Default Module=Off.
CH5/CH14 are forced low on the wire; S1/S2 are CH6/CH7. CH5 is low in the
seven-bar UI as well. This bench restriction is not universal flight-controller
arming or failsafe assurance. [ELRS switch configuration](https://www.expresslrs.org/software/switch-config/)
describes its CH5 arming convention and additional v4 arming methods.

SysTick sends a complete prepacked snapshot every 4ms, independent of the Lua
VM. Main-task services sample/mix/publish every 5ms when they get CPU service;
Lua hooks and bounded drawing calls service that task. These remain cooperative,
and C/GC work is not preempted for mixing. Snapshots at least 100ms old stop RC
submission; a valid new snapshot resumes it. UART copy and tool deadline
reservation are protected against ISR/main races. Router queues remain in the
main task. Lua closing/failing discards its queued requests and generation,
without stopping RC; long PAGE opens Lua, long EXIT returns to native UI.
The whole bench has a 180s RF timeout. No handset USB/Flash installation.

61 checks pass, including periodic frames through a simulated 99ms main pause,
stale suspension, latest sample after busy UART, wraparound, model default Off,
reset/switch/timeout, and actual session Lua queue cancellation while RC keeps
running. The original script also replayed all 33 captured module fields.
Focused independent review found the old UART stop retained RCC enable and
therefore could not reopen. The register-driver reopen test failed before the
fix, then reopen/send/stop passed after stop clears the owned clock enable.

Default RF-off build: 92 ARM objects. RC+Lua+selection-save build: 120 objects,
