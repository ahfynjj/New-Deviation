Native Deviation only. No simulator work, Flash writes or persistent install.

## Completed software checks

Unchanged official ELRS r18 script at commit
`670c8099a91da6c8f5baa44edbdecfacb0e0c6da`, Lua 5.2.4, native compatibility
APIs and a read-only internal USART6 session. The script owns its parameter
UI/parsing; this does not introduce a second settings interface.

55 hardware/tool checks pass, including actual Lua execution with synthetic
fields/folder navigation and complete replay of the 33 captured device fields
from `local/reset-halt-power-20261002-175641.json`. All IDs complete; no writes.
Replay uses private current values without committing them. 64-bit host Lua
arena peak about 209KiB is not a board heap measurement.

Tests cover allocator growth/shrink/failure, uncaught errors, OOM, nested
pcall/xpcall budget swallowing, finalizer denial, route changes, text validation,
UART busy and a second read-only filter beneath Lua. A focused independent
review found one important problem: real fields Pitmode/DVR Rec/HT Enable
contain legacy C0/C1 arrow bytes, unsafe for native UTF-8 rendering. Fixed by
CHAR_UP/DOWN mapping, validated text and padded native lookahead; regression
failed before the fix and passed afterward. No other review blockers reported.

Final Lua build: 116 ARM objects, 464297 bytes of resources, entry
`0x24031549`, BSS end `0x24074c00` below stack at `0x2407c000`.
Strict existing RAM ELF/map checks pass. ELF SHA256:
`238c35fd05731024b146899c1933535f70abb894e48399ec493c5c2db0120072`.
160KiB Lua arena and 16KiB newlib heap are within the AXI app range.
