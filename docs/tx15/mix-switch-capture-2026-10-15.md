# TX15 混控开关拨动选择 SWC1

用户批准：进入 Mix 的 Switch 字段编辑后，拨动 SA–SF 自动选择当前档位；进入编辑不根据已有位置立即改值，摇杆/旋钮不抢选，确认或退出字段后锁定。保留滚轮手选、None 和反向。此次只增强原生 Deviation 现有混控页面，不改射频、模型布局、设置 ABI 或内部启动器。

## 使用

1. 在 Complex 混控的 Switch，或 Expo&DR 的 Switch1/Switch2 上短按滚轮。橙色内框表示正在编辑，普通青色选中框不捕获。
2. 拨动 SA–SF，字段选择新位置对应的来源，例如 SA0/SA1/SA2。每次只接受一个有效开关变化。没有第三触点输入的 SE/SF 仍只能识别当前实际可采集的状态，改装接线问题按用户要求暂停。
3. 编辑期间可转滚轮或按左右键逐项选择，包括 None；长按滚轮将已有开关条件反向一次，松键不会顺带结束编辑。无开关来源时反向操作保持原来的无效行为。
4. 短按滚轮或 EXIT 结束字段编辑，保留当前字段值。EXIT 的整个按下/长按/松开过程由字段接收，不会顺带返回上一页。需要保存整条混控时，仍按原页面 OK；字段确认不替代模型或混控页面的保存操作。

只给这三个 Switch 控件添加捕获角色。其他 Src 字段和其他页面继续原有操作；前面板六键、摇杆、旋钮和微调不参与此次开关捕获。原生主循环执行轻量轮询，读取既有 20ms 去抖后的开关状态，不额外访问外设。

## 生命周期与检查

进入编辑先建立六组位置基线；重复的当前值不发事件。失效或恢复首次有效值仅更新基线，多个开关同一轮变化也只更新基线，避免任意选中一个。输入屏蔽位依旧生效。失去焦点、离开混控页面、控件隐藏/失效以及控件移除时结束编辑，控件存储复用前清理指针。

自动选择复用原生 INPUT_SelectInput 保留反向标志，并与手选共用 set_drsource_helper，以同步混控草稿、曲线及 Expo&DR 开关相关控件。未接入全局 INPUT_CheckChanges，避免将来源字段或其他页面一并改成自动选源。

25 项相关检查通过，包含真实 buttons.c 按键分发链、原生 GUI_DrawObject 选中边框绘制顺序，以及原有 MON1、微调、模型/校准快照、RF 模型、更新包检查。135 个 ARM 对象及独立原生应用构建通过。审查发现的边框被普通选中框覆盖问题已修正：编辑框在选中框之后绘制，使用橙色区分状态。回归检查已先观察到失败，再验证修正。软件检查不等同于实机验收。

## USB 验收

固件：`local/tx15-usb-release/tx15-mix-switch-capture-20261015.ndu`，About 版本 `New Deviation TX15 SWC1`；保留 MON1 监视器及微调修复。通过现有专用 USB 工具更新，保留启动器、模型和校准区。

更新后先用 SA–SD 验证：光标停在 Switch 上但未进入编辑时，拨动不会改值；短按滚轮进入橙框后依次拨动三档，应选择对应位置；移动摇杆/旋钮不抢选。确认后再拨动应保持值。分别试长按滚轮反向、短按 EXIT 结束字段编辑，以及 Expo&DR 从 None 自动选中开关后相关控件是否显示。选好后按 Mix 页面 OK 保存，并正常关机重启确认设置保留。实机结果待用户反馈。
