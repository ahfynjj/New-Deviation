# TX15 内置存储 S0 只读候选

2026-10-16。用户选择遥控器内置存储作为后续语音和模型文件位置。本轮实现手动
SDMMC1元数据读取，尚未访问实机；不格式化、不创建文件、不迁移模型。

## 实现范围

MAIN MENU → Storage test（STO0）→ Scan (read only) 才开始扫描，进入页面和启动时
不自动访问介质。显示状态/错误、MiB容量、SDHC/SDSC、RCA、FAT类型、分区LBA以及
最后CMD/STA/RESP。先读取CID/CSD，再读扇区0和至多一个分区引导扇区；只有初始化及
读取命令，无写入/擦除命令。停止/退出/超时/完成均释放硬件，保留结果供查看。

移植独立于EdgeTX运行框架。固定硬件参考与ST寄存器依据、时钟/DMA及释放顺序见
[硬件所有权说明](../../hardware/tx15/board/storage-notes.md)。原生主循环每轮只推进一个
状态或复制512B，不等待硬件完成；存储不使用IRQ，也不占音频DMA流。RF/输入继续在
现有循环中服务，但实际延迟/射频并行表现尚未实测。

支持SD-v1/v2容量解码、MBR及superfloppy、FAT12/16/32引导参数检查；GPT/exFAT只
标明不支持。坏签名、越界/重叠分区、FAT容量不足和异常参数被拒绝。没有挂载文件系统、
目录列表、文件读取/写入、SOUNDS播放或USB文件传输。设备是SD还是其他协议、容量和
真实文件系统仍须通过实机应答确认，不能因内置称呼直接认定eMMC。

模型1/校准仍沿用NOR双记录，USB更新不更换启动器或保存格式，保留S1/S2 Src自动捕获。
包中保留AUD0提示音页，首次实际试听仍待用户完成；A1离线解析核心尚未接入文件播放。

## 一次 USB 实机验收

1. 接收机断电，按住EXIT开机进入USB UPDATE，连接可靠数据线。
2. 打开 `local/tx15-usb-release/NewDeviationUpdater/NewDeviationUpdater.exe`，连接、
   选择上述STO0包、更新。等待完成后关闭工具，拔USB，正常关机再开机。
3. MAIN MENU → Storage test，选择Scan (read only)，等待约2秒。
   记录状态、容量、文件系统；失败则记录Error/HW/CMD/STA/RESP，不格式化或改线。
4. EXIT返回。若愿意合并试听，可在Audio test选Play 300 ms，记录有无提示音及Errors/
   Underruns；不要求为了这一项先做另一轮更新。

更新固件会写应用Flash；运行Scan只读取存储，两者是不同操作。扫描通过后才进入
有界FAT目录/文件读取，再接SOUNDS及模型INI导出；这版不会改变模型存放位置。
