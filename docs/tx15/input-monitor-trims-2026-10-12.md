# TX15 Input monitor 与微调更新 MON1

用户批准现有监视器的一屏布局改造。SE/SF 改装接线问题按用户要求暂停；不修改其触点引脚或生成虚假第三状态。

原生 480×320 页面使用 Deviation 的 Rect 回调和绘图接口：六组 SA–SF 每组一个三档指示、左右摇杆二维位置、S1/S2 条与百分比、四组物理微调 LV/RV/LH/RH 的值与按键高亮、六个前面板按键。青色边框表示六键当前锁存选择，黄色表示按键正在按下。失效输入显示 `--`；微调未绑定也显示 `--`，有效值以百分比显示（如 `+0.1`）。ENTER 切换只读原始诊断，EXIT 使用原页面返回行为。

读数使用校准后的物理轴，摇杆位置不受用户选择的 Mode 1–4 影响。微调从实际模型绑定中查找，显示当前开关条件选中的微调值，不使用纯按键计数来假装微调生效。20Hz 上限和每个控件的变化比较只重绘发生变化的卡片；诊断切换时重绘背景。静态边界检查和预览使用实机绘图函数及同一字体资源，无模拟器项目。

最新 USB 自动备份中的 v2 模型（3404 字节）证实十个微调项均未绑定。产品默认 CRSF 模型原来省略了 `[trim1]`–`[trim4]`，所以按键采样虽已实现，模型没有相应微调项。新版模板补齐四组物理轴绑定；加载旧模型后，只有所有微调的来源、按钮、条件开关、值及自定义步长均未配置时，才在 RAM 中补齐默认四组。已有任何自定义微调时整体保留；不改变 Mixer 的 `usetrim`、限位、安全、射频或校准配置。

兼容修复本身纳入加载后的 CRC 基线，不在开机时自动写 Flash。后续微调按键或模型编辑使模型变更，正常保存/电源键关机沿用现有快照流程；未操作时下次启动再次在 RAM 补齐。真实备份的离线修复验证通过，除微调绑定外的全部模型字节保持一致。快照版本、结构大小和 USB 设置 ABI 均不变。

针对性 22 项检查通过，覆盖物理按键影响真实混控、四种 Mode、长按/松键、禁用 `usetrim`、保留自定义微调、ENTER 与自定义微调冲突、故障输入显示和绘图边界、保存失败保持变更、现有 RF 模型与 USB 包拒绝规则。133 个 ARM 对象构建、ND15 与包内镜像一致性、CRC 和 MON1 标记核对通过。审查发现的 ENTER 回调优先级问题已通过回归检查并修正。实机显示、方向和微调关机保存仍待验证。

USB 文件：`local/tx15-usb-release/tx15-input-monitor-trims-20261012.ndu`。正常关机，按住 EXIT 开机进入 USB UPDATE，接好数据线，通过专用工具选择该包更新。工具完成后关闭窗口、拔掉 USB、正常关机再开机。保留内部启动器和设置区。

验收：进入标题为 `Input monitor MON1` 的页面，确认两根摇杆及 S1/S2、已正常工作的开关、六键和 ENTER/EXIT；分别按四组微调，确认对应高亮及数值变化，同时在 Channel monitor 核对目标通道输出变化。正常按电源键关机再开机，确认微调值、原模型和校准保留。默认微调步长为 0.1%，通道监视器若仅显示整数百分比，需按数次才能看到整数变化。恢复微调中心后再验收内置 ELRS 保持连接约一分钟。具体包身份与证据见 `evidence/2026-10-12/input-monitor-trims.json`。
