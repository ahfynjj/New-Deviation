# TX15 ELRS正式集成

用户确认：触摸后移；MAIN MENU独立ELRS Lua入口；Model setup分别设置内置/外置RF开关及CRSF协议，当前只支持ELRS。两模块开启时选择Lua目标。模块关闭停止串口并关闭相应供电。配置需随模型保存。

复用原生Deviation GUI/混控及已有Lua/CRSF台架实现，不替换应用框架。

实施顺序：
1. MAIN MENU入口替代长按PAGE快捷键，保留实体键操作。
2. 独立双模块模型字段和配置页面；默认关闭，不用旧单协议字段推断供电。
3. 模型保存后端和模块路由；内置/外置各自调度，Lua只访问所选模块。
4. 去除台架专用超时及通道覆盖，加入正式持续输出与启动安全检查。
5. 构建独立启动候选、准备当前已安装版本备份与恢复，再更新验收内置Lua参数/RC输出。

当前已实现第1项及第2项的模型字段、INI读写和配置控件；内置路由改为使用新字段，默认关闭、非法值不启用。INI写出已接入，但存储后端仍只读，尚不能断电保存。124对象ARM Lua/RC构建及模块配置、路由测试通过；未进行本轮实机验收。现有USART6仅支持内置；外置尚未接通。现有RC台架有180秒期限、CH5/CH14强制低，不能直接作为正式固件。当前持久固件仍RF关闭，未刷入这轮代码。外置硬件验收待模块到位。
