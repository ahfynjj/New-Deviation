容量依据：[ST RM0433 电子签名章节](https://www.st.com/resource/en/reference_manual/rm0433-stm32h742-stm32h743753-and-stm32h750-value-line-advanced-armbased-32bit-mcus-stmicroelectronics.pdf)、[STM32H750 官方资源说明](https://www.st.com/en/microcontrollers-microprocessors/stm32h750-value-line.html)。

## 19:32 电源引脚源码与实机只读核对

用户明确允许参考 EdgeTX 的 TX15 硬件适配，原生 Deviation 应用路线不变。

- [TX15 hal.h](https://github.com/EdgeTX/edgetx/blob/main/radio/src/targets/tx15/hal.h) 定义 `PWR_ON_GPIO=PH12`、`PWR_SWITCH_GPIO=PA4`。
- [公共电源驱动](https://github.com/EdgeTX/edgetx/blob/main/radio/src/targets/common/arm/stm32/pwr_driver.cpp) 的 `pwrOn()` 配置输出并置高，`pwrOff()` 清低；按钮为上拉输入、低有效。
- [TX15 构建定义](https://github.com/EdgeTX/edgetx/blob/main/radio/src/targets/tx15/CMakeLists.txt) 使用 rm-h750 板级驱动和公共电源驱动。以上链接为查阅时的 main，尚未固定提交号，实施驱动前需固定来源版本。
- 地址依据 [ST STM32H750 CMSIS 头文件](https://github.com/STMicroelectronics/cmsis-device-h7/blob/master/Include/stm32h750xx.h)：GPIOH 基址 `0x58021C00`，GPIOA 基址 `0x58020000`，RCC_AHB4ENR `0x580244E0`。

实机以 100 kHz、attach、`init_board=False` 读取，未复位、暂停核心或修改 GPIO/Flash：

| 寄存器 | 读取值 |
|---|---|
| DHCSR | 0x03010000 |
| RCC_AHB4ENR | 0x110007FF |
| GPIOH_MODER | 0xFDD4A3FF |
| GPIOH_OTYPER | 0x00000000 |
| GPIOH_PUPDR | 0x00010000 |
| GPIOH_IDR | 0x000015C0 |
| GPIOH_ODR | 0x00001400 |
| GPIOA_MODER | 0xAAAC70FE |
| GPIOA_PUPDR | 0x64010502 |
| GPIOA_IDR | 0x0000DD90 |

解码：PH12 为推挽通用输出、无上下拉、ODR/IDR 均为 1；PA4 为上拉输入、IDR 为 1；核心未暂停。与参考源码相符，支持软件电源保持解释，但尚未直接观测复位时 PH12 的电压变化或确认电源按钮的硬件旁路。

脚本：`local/hardware-session/read-power-pins.py`；原始记录：`local/power-pins-20260926-193249.json`。脚本只写 DP/AP 访问配置；GPIO 时钟未打开时会停止，不自行开启。

下一次测试需要用户配合：先确认按钮能在短时复位期间保持供电，再决定 reset-halt 与 PH12 接管顺序。PH12 输出高不能让被持续复位的 CPU 执行程序，因此不能只往 RAM 入口加电源初始化就宣称该问题已解决。

## 19:38–19:39 按键输入与按住按钮时的复位访问

- 用户反馈上一轮按下时原固件执行关机提示，随后屏幕仍亮。不能以该现象判定按钮无效或电源保持失败。
- 改为 120 秒只读监测，经交互问题提示短按：PA4 在 23.562 秒变低、24.093 秒恢复高，约 0.531 秒；用户确认已短按。这验证了实际按钮输入与源码一致。
- 再次等待按下，成功检测后拉低 NRST；探针读回 NRST 已拉低，在该状态下仍读出 `CPUID=0x411FC271`。
- 随即释放 NRST，约 2 秒后读取成功：`DHCSR=0x03010000`、`GPIOH_MODER=0xFDD4A3FF`、`GPIOH_IDR=0x15C0`、`GPIOH_ODR=0x1400`。原固件处于运行状态，PH12 为输出高。
- **范围限制**：末次 PA4 仍为低，证明的是按住按钮期间 SWD/核心访问可用；尚未证明暂停 CPU 后松手可保持供电，没有量测此次复位期间 3V3 波形。
- 未暂停核心、装载 RAM、写入 Flash 或选项字。原始记录：`local/button-monitor-20260926-193846.json`、`local/button-reset-20260926-193927.json`。
