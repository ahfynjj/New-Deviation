# TX15 AV03 音量与局部重绘修正

**后续实机反馈：系统非常卡顿，本版性能未通过，不再推荐。** 优先使用
[AV04直接绘制恢复版](display-restore-2026-10-18.md)。下文保留当时实现及软件证据，
不代表画面或操作流畅度验收成功。

2026-10-18。用户确认最大音量仍很小，屏幕闪烁主要集中在画面变化处。既有反馈已确认
STO2识别介质并听到合成音；本轮不重复要求同样的存储探测。没有声压、屏幕视频或电气
测量，因此本版仅修正已定位的软件限制/重绘路径，实际音量和画质仍待用户验证。

## 音量

原最大档5仍写Speaker Volume1寄存器46为40，约20dB衰减；默认3写56，约28dB衰减。
本版保持0..5，档位1..5改写72/48/24/12/0，默认3约12dB衰减，最大5不额外衰减。
0仍通过寄存器48关闭扬声器增益；默认比旧版约提高16dB，最大比旧版约提高20dB，
这是寄存器配置变化，不是测得的声压提升。

DAC-6dB、功放+6dB、合成波形峰值8192/32768及淡入淡出均不变，不提高功放档位或
修改供电/音频时钟。依据已下载的[TI TAS2505指南](https://www.ti.com/lit/ug/slau472/slau472.pdf)
Page1 Reg46/48。Audio test标题AUD3。本版不增加自动语音、音量保存或WAV播放。

## 画面

现有GUI标签/条形图在正在扫描的帧缓冲内擦背景再画内容，LCD_ForceUpdate为空；
Lua填充也直接写同一缓冲。用户能看到局部擦除过程，与本次描述相符。这一代码缺陷
不证明历史整屏/背光明暗闪动的原因；不改LTDC时序、PLL、背光、面板命令或启动器。

新增可选 `TX15_BUFFERED_DISPLAY=1`，仅允许原生standalone product。应用启动完成
装载、恢复模型后，复用已经过期的boot staging前307200B，即D0100000..D014B000，
保存后台画面。资源仍为D0080000..D0100000，原显示缓冲仍为D0000000..D004B000。
RAM bench/启动器/USB updater不启用此功能，ND15段地址及加载白名单不变。

绘制写后台；GUI已有的LCD_ForceUpdate只将已完成的脏矩形复制至原显示缓冲，不提交
无变化帧。Lua填充与每轮脚本输出也使用同一路径。绘制和提交每512像素操作调用硬件
服务，在初始GUI/RF完成后绑定CLOCK_ResetWatchdog；回调不调度按钮/GUI绘制，递归
present受busy保护。启动阶段首次拷贝尚未开启RF，不回调运行服务。

这是后台合成后的一次复制，不是垂直消隐换帧；复制期间仍可能出现撕裂。大范围变化
仍可能需要复制全屏，实际耗时/RF并行尚未测量。本版针对多次擦除/绘制带来的闪烁，
不声称消除所有显示问题，不扩大为完整双缓冲或高帧率验收。

[证据](evidence/2026-10-18/audio-display-fix.json)。
