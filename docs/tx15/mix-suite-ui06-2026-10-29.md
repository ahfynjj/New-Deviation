# UI06：MIX 整体界面适配

范围按用户要求扩展为整条原生 MIX 操作链，使用统一深色背景、橙色编辑
状态、整行参数卡片与大触摸区域，继续使用 Deviation 混控及模型逻辑。

## 页面覆盖

- Mixer 列表：沿用五行大触摸列表、通道限位／混控入口、Monitor／Order、
  滑动与 Previous／Next。列表按钮改为统一动作样式。
- None／模板选择：统一标题、模板编辑和 Cancel／OK；没有混控时明确显示
  No mixer。直升机 cyclic 模板保持原本无独立参数的语义。
- Simple：整行 Source／Curve／Scale／Offset、统一预览面板和输出数值。
- Complex：统一主页面及 More 中的 Mixers／Mixer 参数卡片，保留 Trim。
- Expo/DR：Next rate 在 High／Mid／Low 间切换；共享 Source，各档独立的
  Switch／Curve／Scale／曲线关联设置。关闭的档位不开放曲线和倍率，关联
  曲线也不开放独立编辑入口。Edit curve 按钮与回调都检查同一权限。
- 曲线：Curve／Smooth／Point／Value、选中点标记、Cancel／OK。图内短点
  抬手可选择／设置点，支持反向输入映射；不支持连续拖拽。
- 限位：十个参数分两屏，包含 Reverse、Fail-safe、Safety、Safe value、
  Min／Max、正负 Scale、Subtrim、Speed。FS: On/Off 可触摸切换失控保护
  启用状态，Revert 恢复进入页面时的值。**此页沿用实时修改，Back 不取消
  修改**，因此没有误导性的 OK／Cancel 按钮。
- 排序：Selected／Copy to、Move Up／Down、Copy To、Insert／Remove、列表
  点选及翻页、Save／Cancel。新增／删除仍按原调用者允许的模式显示。

共享系统键盘（虚拟通道重命名）及 Monitor 工具不是此次重绘页面。没有
增加数值键盘或选择弹窗；参数沿用点选进入编辑、左右各 40px 减／加、
中间确认和实体滚轮。短按 EXIT 结束参数编辑；长按滚轮保留原辅助操作。

## 触摸与存储边界

使用有界页面目标表，隐藏、移除、禁用对象不接收点选。页面、分页或重建
发生时取消旧手势；滚动行对象复用也改变世代编号。图坐标严格在边界内
映射，手指拖动／长按不重复写值。共享 Source／Switch 的实际编辑所有权
和硬件捕获逻辑，不另建混控数据副本。

同时修复原排序删除循环在满容量时读写尾部之外的问题，guard 回归先失败
再通过。启动器、USB API 1、设置 ABI 1、模型和校准格式保持不变；未修改
RF、音频或存储驱动，也未访问／刷写实机。
