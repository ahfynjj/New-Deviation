# TX15 语音 A0：内存与首次发声候选

按[语音计划](../superpowers/plans/2026-10-15-tx15-native-voice.md)推进第一阶段，当前交付可 USB 更新的低音量合成提示音诊断版。尚未验证实机声音，未实现 WAV、语音包文件读取、系统自动播报或 Lua 音频 API；不能据此宣称完整语音可用。

## 本轮实现

1. 保持 Lua 堆160KiB容量，把音频启用构建中的堆迁入 D2 SRAM，单独预留32KiB音频工作区，显式初始化；保持现有启动器和16KiB栈。
2. 原生 TAS2505/I²S2/DMA 后端，单次 I²C 交易有1ms截止时间，初始化按主循环分步执行；失败静音并显示 Error，不等待用户拆机测量。
3. MAIN MENU → Audio test：手动 Play 300 ms、Stop、Volume -/+；默认音量3/5，0静音，低音量上限5。进入页面不会自动发声，退出页面停止并复位音频芯片。
4. 通过独立 PLL2 生成音频时钟，保留 LCD PLL3 与主时钟；模型保存检查允许已稳定的音频 PLL2。关机先停止音频，再执行原保存流程。

详细所有权、工作区、引脚、寄存器资料和阶段边界见[硬件记录](../../hardware/tx15/board/audio-notes.md)。已有 SRC1、MON1、模型/校准和 ELRS 代码保留；S1/S2 自动选源的实机反馈仍待确认。

## 验证与待验收

34项相关软件检查通过（22.526秒），包含实际 Lua/官方 ELRS 脚本运行、控制器故障注入后开关采样、DMA 缺数据静音与错误停机、音频菜单动作、模型/校准快照和更新包。140个 ARM 对象构建及原生装载验证通过；应用 `_bss_end=0x24054390`，距固定栈底余162928字节。主机 Lua 峰值低于160KiB不等同于实机 D2 工作区验证；音频关闭的137对象对照构建也通过。

集中只读审查未发现默认音量下的阻断项；提出的首次播放静音时序边界已进一步修复：必须应用选定音量/静音后，才允许排入首段PCM。回归测试先观察失败，再验证修正。

只读审查和最终打包结果写入[证据](evidence/2026-10-16/audio-a0.json)。本轮软件工作不访问遥控器，不擦写其 Flash；USB 安装、真正发声、显示/开关/输入和 ELRS Lua 操作需要用户反馈。A0 退出条件仍未满足，待合并验收后继续 A1 播放核心。

## 一次 USB 合并验收

固件 `local/tx15-usb-release/tx15-audio-a0-20261016.ndu`，About 版本 `New Deviation TX15 AUD0`。更新仅替换外部应用，设置 ABI1、NOR 模型/校准布局和内部启动器不变。

1. 接收机先保持断电。按住 EXIT 开机进入 USB UPDATE，用现有专用工具更新此文件，完成后关闭工具、拔 USB，正常关机再开机。
2. MAIN MENU → Audio test，确认初始 Off/Volume3。选 Play 300 ms：应从 Starting/Configuring 进入 Ready，听到一次短提示音；可重复试听。声音太轻时再用 Volume +，最多5；Volume0应静音。回复是否可听、是否异常噪声，以及 Errors/Underruns 数字；若没有声音，回复页面状态和DMA数字，不追加盲目刷写。
3. EXIT 返回后检查输入监视器、滚轮和微调，再进入 ELRS Lua 浏览 TX Power 后短按 EXIT 返回。本轮不需改射频参数或重新校准。正常关机再开机，确认原模型/校准仍保留。
4. 如方便，再给接收机上电，确认 ELRS 连接保持约一分钟。30分钟语音/RF负载验收留到后续真正的资源播放阶段。

需要回退时，用同一 USB 流程刷回 `tx15-s1-s2-source-capture-20261015.ndu`；这是已构建的 SRC1 包，勿改动模型/校准区域。音频测试期间 Stop 或 EXIT 可结束声音。

构建增加 `TX15_AUDIO=1`，其他产品标志与语音计划一致；输出 `local/tx15-hardware/audio-a0-20261016/app`。音频关闭的对照构建放在同目录 `audio-off`。后续继续 A1 WAV/队列，再做 A2 实际介质读取；本轮不要求重新焊接 PWLINK2。
